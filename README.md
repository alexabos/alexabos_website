# abos.github.io

Alexandra Abos' personal website built with Jekyll.

## Local setup

### Version constraints

- Ruby `3.1+` (recommended: `3.2.x`)
- Bundler `2.5+`
- Node.js `18.x`
- npm `8+`

### Install dependencies

```bash
bundle install
npm install
```

### Build assets + site

```bash
npm run build
bundle exec jekyll build
```

### Run locally

```bash
bundle exec jekyll serve
```

The site will be available at `http://127.0.0.1:4000/`.
